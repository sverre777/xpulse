# Ikonsettet

`components/ui/ikoner.tsx`: fyll via potrace, strek via midtlinje (skjelett), 24x24-boks.
Farge (currentColor), størrelse (14/18/22/26) og strektykkelse (1.7) styres av komponenten
`<Ikon navn=... variant=... storrelse=... />`, ikke av arkene.

Merknader:
- `skyting` står på ark 01/02 (Handlinger) og ark 05 (Idrett) med samme form; ark 05 er brukt.
- Ark 09 sitt lyn («Watt») er erstattet av ark 15: lynet heter `aktivitet` (aktivitet/drag), `watt` er måleren med full sirkel.
- Ark 13 sitt termometer («Sykdom») er erstattet av ark 15 sitt kors (`sykdom`); termometeret lever som `termometer` for temperatur/vær.
- `tempo` = måler med halvbue (ark 09); `watt` = full sirkel (ark 15). Skilles også av farge i konteksten.
- `mer` (fire ruter) og `multisport` (tre ruter + pluss) skal aldri stå i samme rad/meny.
