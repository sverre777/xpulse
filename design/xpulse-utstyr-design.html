Notat — regler

  • Kategorispesifikt skjema: basen er felles (som i dag) + «km allerede gått» for ALT utstyr — start-km legges til km-tellingen, historisk utstyr starter ikke på null. Kategoriens egne felter vises under basen.
  • Ski: lengde · type (skøyte/klassisk/stake) · bruk (trenings-/konkurranseski) · slip m/ årstall/dato. Lagres → rett inn i skiparken, med type/bruk/slip som filtre der.
  • Slip er HISTORIKK: ny slip legges alltid OPPÅ (navn + dato/årstall — årstall holder), gamle beholdes, «km siden siste slip» nullstilles ved ny. Aldri overskriving.
  • Rulleski er EGEN kategori — har ikke slip. Felter: type (skøyte/klassisk), hjultype, rullemotstand — én felles ELLER ulik foran/bak.
  • Skisko: størrelse + type (skøyte/klassisk/kombi). Løpesko/sykkelsko: størrelse. Skistaver: lengde + bruk. Sykkel: type, drivverk, hjulsett. Klokke/annet: kun basen.
  • Kategoriene utvides fra dagens ['sko','sykkel','ski','klokke','annet'] — eksisterende rader BEHOLDES og mappes (dagens 'sko' → løpesko som default; migrering m/ SQL til godkjenning, prod-skjema verifiseres først).
  • Skipark-tester: maler ⏱ tidtaker-glid · 📏 lengde-glid · ⚔ parallelltest + EGNE tester (lagres som mal). Gjenbruker eksisterende skitest-modell (entries + rank_in_test) — dette utvider, erstatter ikke.
  • Forhold på alle tester: sted · vær · føre · temp LUFT og SNØ · luftfuktighet · notat. «Under skiene» per ski — ved smøretest er det selve testvariabelen (samme ski kan stille flere ganger m/ ulik smøring).
  • Parallelltesten: paringer auto fra valgte ski, oddetall gir frirunde, ett trykk markerer vinner, vinneren videre til neste runde. Resultat = rangering → lagres som vanlig skitest så «beste ski per føre» fanger den.
  • Funksjonsparitet: alt dagens (km-telling, smøring, rangering per føre, tester) beholdes 1:1 — dette er utvidelse + redesign av skjemaet.
  • Mobil (375px): alt i én kolonne, chips wrapper, bracket stables vertikalt.
